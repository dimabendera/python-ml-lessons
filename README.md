## Як читати

Лекції, тести й домашні завдання — звичайні HTML-сторінки. Відкриваються в браузері,
нічого встановлювати не треба.

Практичні зошити — `.ipynb`. Щоб запускати їх у себе:

```bash
pip install -r requirements.txt
jupyter notebook
```

**Окрема умова для курсу «Обробка природної мови».** Його зошити не завантажують
нічого з мережі: корпусом їм служать українські переклади програм, які **вже стоять
у системі**, — файли `/usr/share/locale/uk/LC_MESSAGES/*.mo`. На українській або
багатомовній Linux-системі вони є (на машині, де писався курс, — 273 файли).
На системі без українських перекладів більшість зошитів цього курсу **не
запуститься**: вбудованого запасного мінікорпусу на 105 рядків вистачає лише темі 01.
Перевірити, що у вас є:

```bash
ls /usr/share/locale/uk/LC_MESSAGES/*.mo | wc -l
```

І чесно про наслідок: набір встановлених програм у кожного свій, тож **числа ваших
прогонів не збігатимуться з числами лекцій**. Ми це заміряли, і виявилось, що
розходиться не все:

| | 50 програм | 273 програми |
|---|---|---|
| документів | 29 222 | 190 823 |
| словоформ | 12 385 | 47 659 |
| **нахил Ципфа** | **−1.0011** | **−1.0177** |

Обсяг змінюється в шість разів, **закон — ні**. Тому підрахунки в лекціях («стільки
документів», «стільки словоформ») читайте як «стільки вийшло на машині, де курс
писався», а перевіряйте на своїй те, що має відтворитись: нахили, співвідношення й
напрямок висновку. Кожен зошит друкує свої числа сам, тож розбіжність буде видно
одразу.

Кожен зошит має вигляд-двійник `practice.html` — його можна просто переглянути
в браузері разом із результатами виконання, без запуску.
